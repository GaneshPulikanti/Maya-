┌───────────────────────────────────────────────────────────────────────────────┐
│ HOW IT WORKS                                                                  │
├───────────────────────────────────────────────────────────────────────────────┤
│                                                                               │
│  1️⃣  USER SPEAKS                                                              │
│      └─ Taps microphone button in voice modal                                │
│                                                                               │
│  2️⃣  AUDIO RECORDING                                                          │
│      ├─ Android device? → Try Capacitor plugin (native)                    │
│      └─ Fallback → MediaRecorder API (web/unsupported)                     │
│                                                                               │
│  3️⃣  UPLOAD TO BACKEND                                                        │
│      └─ POST /api/voice/transcribe (multipart form-data)                   │
│                                                                               │
│  4️⃣  TRANSCRIPTION                                                            │
│      └─ Groq Whisper API (whisper-large-v3-turbo)                          │
│         └─ Returns: { "text": "What time is it?" }                         │
│                                                                               │
│  5️⃣  CHAT INTEGRATION                                                         │
│      ├─ Text appears in chat input                                          │
│      ├─ User can edit or send immediately                                   │
│      └─ Message sends to AI                                                 │
│                                                                               │
│  6️⃣  AI RESPONSE                                                              │
│      └─ AI generates response text                                          │
│                                                                               │
│  7️⃣  TEXT-TO-SPEECH                                                           │
│      ├─ POST /api/voice/speak                                               │
│      └─ Groq Orpheus (canopylabs/orpheus-v1-english)                       │
│         └─ Returns: WAV audio bytes                                         │
│                                                                               │
│  8️⃣  PLAYBACK                                                                 │
│      └─ Audio plays to user ("It's 3:45 PM")                               │
│                                                                               │
│  9️⃣  LOOP                                                                     │
│      └─ Auto-return to listening for next input                            │
│         (Or user can interrupt by speaking again - ChatGPT style)           │
│                                                                               │
└───────────────────────────────────────────────────────────────────────────────┘
