═══════════════════════════════════════════════════════════════════════════════
                           ERROR HANDLING FLOW
═══════════════════════════════════════════════════════════════════════════════

  Recording Phase:
  ├─ Microphone denied ──► Show "Permission Denied" error
  ├─ Audio too short ────► Show "Speak longer" prompt
  └─ Recording crash ────► Show error + offer retry

  Transcription Phase:
  ├─ No internet ────────► Show "Connection error"
  ├─ Groq API error ─────► Show "Transcription failed"
  └─ Empty response ─────► Show "Didn't catch that"

  TTS Phase:
  ├─ Groq unavailable ──► Fallback to Web Speech API
  ├─ Network error ─────► Show "Playback failed"
  └─ Audio corrupt ─────► Skip to listening phase

  Recovery:
  └─ All errors offer: "Try Again" button to restart
